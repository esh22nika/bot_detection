## SUPPORTED WITH CAVEAT (v0.4)

| # | Claim | Caveat |
|---|---|---|
| V4-C1 | "da_localized beats periodic_4" | True (Δ=+0.0019, 4/5 seeds). But static beats both. Pre-registered positive threshold Δ≥0.01 not met. Reported as Outcome B, not Outcome A. |
| V4-C2 | "da_localized uses fewer retrains than best periodic" | True (1.0 vs 2.0 for periodic_6). Framing as efficiency is valid but da_localized F1 is still below static (0 retrains). |
| V4-C3 | "Static outperforms all adaptive methods on v0.4" | True, but this is a property of v0.4's higher baseline separability — NOT a general finding. On data with more degrading drift, adaptive methods would have larger advantage. |
| V4-C4 | "The localized detector provides interpretability" | True as a design claim. But on v0.4, the detector fires only ~1× per run, limiting how often attribution is triggered. |
| V4-C5 | "Per-scenario results" | Per-scenario test accounts for Protocol A contain only bots (humans are drift_scenario='none'). Per-scenario F1 on bot-only subsets is not directly comparable to aggregate F1. Results are exploratory. |
| V4-C6 | "Protocol B F1 = 0.98+" | Account-level leakage: all 1000 accounts train AND test in Protocol B. Clearly labelled as secondary. |
| V4-C7 | "0 false alarms before drift onset" | Verified for train-account monitoring across 5 seeds. Does not guarantee zero false alarms in held-out populations. |
| V4-C8 | Recency decay λ = 0.7 in v0.4 | Paper text Section 4.6 (Eq 4e) states λ=0.3. This MUST be corrected. The implementation uses λ=0.7 (run_final_v04_complete.py line RECENCY_DECAY=0.7). |
